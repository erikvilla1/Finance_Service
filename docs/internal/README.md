# Internal notes

Working documents from the build, kept for history rather than as current
reference. They were at the repository root and moved here so the root reads
as a project rather than as someone's desk.

Nothing in this folder is authoritative. Where one of these disagrees with the
code, the code is right.

| File | What it was for |
|---|---|
| `FOR_KAI.md` | Handoff notes between the two people working on the build |
| `FOR_KAI_MIGRATIONS.md` | Which migration numbers were taken, and by whom |
| `KAI_BRANCH_SYNC.md` | Reconciling two branches that had both added columns to one table |
| `KAI_TODO.md` | A point-in-time task list |
| `PR12_HANDOFF.md` | Review notes for one pull request, mostly about the password policy |

For what the platform is and how it is built, see the repository's
[`README.md`](../../README.md). For the original product specification, see
[`docs/PLATFORM_SPEC.md`](../PLATFORM_SPEC.md).
